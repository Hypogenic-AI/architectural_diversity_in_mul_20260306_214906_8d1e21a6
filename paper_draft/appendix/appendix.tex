\subsection{Debate Protocol Prompts}
\label{app:prompts}

The \debate condition uses three system prompts:

\para{Proposer prompt (\haiku).}
\begin{quote}
\small
You are a careful reasoner. Some questions contain misleading surface patterns
designed to trick you. Identify these patterns and reason step-by-step to the
correct answer. State your final answer clearly with ``FINAL ANSWER:'' at the end.
\end{quote}

\para{Critic prompt (\sonnet).}
\begin{quote}
\small
You are a critical reviewer. Carefully evaluate the following answer for logical errors,
incorrect assumptions, or missed insights. Point out specific flaws in the reasoning.
If the answer is correct, say so clearly. Be concise and specific.
\end{quote}

\para{Reviser prompt (\haiku).}
\begin{quote}
\small
You previously proposed an answer. You have now received a critique.
Consider the critique carefully. If it reveals a genuine error, correct it.
If you believe your original answer was correct, maintain it with justification.
State your final revised answer with ``FINAL ANSWER:'' at the end.
\end{quote}

\subsection{Compute Resources}
\label{app:compute}

All experiments ran on CPU only (no GPU), Linux, 2 CPU cores.
API latency was approximately 2--5 seconds per call.
Total execution time was approximately 33 minutes (25 minutes for the main
30-question experiment plus 8 minutes for the paraphrase set).
An API key interruption at question~15 required resuming in a second session;
results appeared consistent across both sessions.
Total API calls: approximately 310
(30 questions $\times$ $\approx$8 calls per question for all conditions,
plus 6 paraphrase questions $\times$ $\approx$4 calls).
